## Next.js version warning

`package.json` pins Next 16.4.3 / React 19.3 / Tailwind 4, which differ from older Next.js. Per `AGENTS.md`, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) before writing Next.js code, and heed deprecation notices. `AGENTS.md` is regenerated by `next dev`.

Config specifics in `next.config.ts`: `cacheComponents: true`, `partialPrefetching: true`, `experimental.agentFeedback`, and a Turbopack rule that runs `*.css` through `@tailwindcss/turbopack`. Route props use the global `LayoutProps<"/">` type (see `app/layout.tsx`). Path alias: `@/*` maps to the repo root.

## Current state and architecture

The Next.js app (`app/`, App Router) is still the Create Next App scaffold: `app/page.tsx` and `app/layout.tsx` (title "Create Next App") have not been replaced yet.

The real design source is `resources/templates/`, a standalone prototype to port into the Next app. It is not part of the Next build (and is currently untracked in git):

- `Arcade Vault.html` loads React 18 UMD and Babel standalone from unpkg and runs each `.jsx` file as a `text/babel` script. Files share globals rather than using modules, which is why `app.jsx` aliases hooks like `useStateApp`. Porting means converting these to ES modules and components.
- `data.jsx` holds mock data (`GAMES`: id, title, cat, cover class, color, best score, plays).
- Screens: `biblioteca.jsx` (Library), `detalle.jsx` (GameDetail), `reproductor.jsx` (GamePlayer), `auth.jsx` (Auth), `salon.jsx` (HallOfFame), plus `nav.jsx`.
- `app.jsx` is a hash router. The route is a JSON object (`{name: "biblioteca" | "detalle" | "player" | "auth" | "salon", id?}`) kept in `location.hash`. The prototype's state lives in `localStorage`: `av_user` for the session and `av_scores` for the score list. In Next this should become real routes, and persistence is not yet decided.
- `styles.css` (~950 lines) is the whole visual system (neon/retro theme, CSS variables like `--line`, `--ink-faint`, `--mono`; fonts Press Start 2P, Courier Prime, JetBrains Mono).
